## 🚀 Встановлення

1. **[Завантаж NG-Helper-Setup.exe](https://github.com/XomyakDru/NG-helper/releases/latest/download/NG-Helper-Setup.exe)** і запусти. Це інсталятор Richi Wiki.
2. Готово: закони й правила завантажаться самі, **входити в акаунт не потрібно**.

> **GTA має працювати в режимі «У вікні без рамки» (Borderless)**, інакше вікно не буде видно поверх гри.
>
> Windows може показати «Невідомий видавець»: натисни **Детальніше → Виконати все одно**. Так буває з безкоштовними програмами без платного підпису.

## ⌨️ Клавіші

| Дія | Клавіша |
|---|---|
| Показати / сховати вікно | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> |
| Закріпити поверх гри / повернути керування | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> |
| Помічник збоку: розгорнути й писати | <kbd>Alt</kbd>+<kbd>Q</kbd> |
| Відкрити Richi Wiki | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>W</kbd> |
| Закони ↔ Правила | <kbd>Tab</kbd> |
| Пошук ↔ ШІ | <kbd>Shift</kbd>+<kbd>Tab</kbd> |
| Сказати голосом | <kbd>Ctrl</kbd>+<kbd>Space</kbd> |
| Копіювати статтю з покаранням | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| Шпаргалка / Історія | <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>Ctrl</kbd>+<kbd>H</kbd> |

Усі клавіші змінюються в **Налаштування → Клавіші**.

## ❓ Питання

<details><summary><b>Це чит? Мене не заблокують?</b></summary>

Ні. Richi Wiki — окрема програма-довідник: вона не втручається в гру, не читає її пам'ять і нічого не змінює в GTA. Це як відкрити сайт з законами, тільки зручніше.
</details>

<details><summary><b>Це безкоштовно?</b></summary>

Так. Пошук, Wiki й калькулятори без обмежень. ШІ дає 50 безкоштовних запитів на день, залишок видно в рядку статусу.
</details>

<details><summary><b>Треба входити в акаунт ng-gta5.com?</b></summary>

Ні. Закони й правила програма завантажує сама, без логіна й пароля.
</details>

<details><summary><b>Раніше вона називалась NG Helper?</b></summary>

Так, це та сама програма. Якщо NG Helper уже встановлений, він сам оновиться до Richi Wiki, і налаштування та шпаргалка збережуться.
</details>

<details><summary><b>Не видно вікна поверх гри</b></summary>

Перемкни GTA в режим «У вікні без рамки» (Borderless) у налаштуваннях графіки. Якщо гаряча клавіша не працює, її могла зайняти інша програма (Discord, NVIDIA, OBS): зміни її в Налаштування → Клавіші.
</details>

<details><summary><b>Як оновити?</b></summary>

Нічого робити не треба: програма сама запропонує оновитися, коли вийде нова версія.
</details>
